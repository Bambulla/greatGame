# greatGame

Консольная мини-игра «Змейка» на C# (.NET 8).

## Запуск

```bash
dotnet run
```

## Управление

- Стрелки или `WASD` — движение
- `Space` — пауза
- После проигрыша: `Enter` — новая игра, `Esc` — выход

Если заполнить всё поле змейкой, игра завершится победой.

Рекорд сохраняется в `highscore.txt` рядом с исполняемым файлом.
